# wanted-hackathon

원티드 AI Championship 2026 출전 레포. 과제 제출 마감 2026-09-20.

## 문서 지도

- `docs/rules.md` — 대회 룰, 심사 기준·배점, 일정, 심사위원
- `docs/challenge.md` — 오픈 토픽 해석, 제공 리소스
- `docs/research/` — 심사위원·파트너사 리서치
- `docs/problems.md` → `opportunity_sizing.md` → `solutions.md` → `decision.md` — 문제 정의에서 최종 결정까지
- `docs/measurement.md` — 지표 계획
- `docs/loop.md` — 반복 작업 루프 정의
- `AGENTS.md` — 에이전트 작업 컨벤션
- `devin_playbook_hackathon.md`, `hackathon_builder_workflow.md` — 이 레포가 따르는 워크플로우

대회 페이지: https://event.wanted.co.kr/ai-championship/2026
