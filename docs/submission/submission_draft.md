## AI 활용 방식 및 결과 (500자 제한 — 확정본 425자)

```
제작 과정과 서비스 런타임 모두에 AI를 썼습니다. [제작·루프 엔지니어링] Codex 에이전트로 해커톤 룰→시장 리서치(NotebookLM+검색으로 컨텍스트 빌딩)→문제 정의→기회 사이징→솔루션 우선순위→스캐폴딩(AGENTS.md·파일구조)을 단계별 프롬프트 파이프라인으로 자동화하고, 자체 평가 하네스(13케이스·4회 반복)로 프롬프트 회귀를 데이터로 측정해 동결. [서비스·3단계 추론] 자연어 업무 서술→①LLM이 단계 분해·5축 적합도 점수화·실행 가능성 3종 분류(즉시 실행/연동 필요/사람 판단) ②선택 단계를 샘플 데이터로 실제 1회 실행해 결과물+SOP 생성 ③회사 양식 그대로 채우고, 결과물 수치를 코드가 재계산해 검증 카드로 표시(LLM 자기검증 아닌 결정적 계산 — 오계산 적발). 결과: 실행 성공 100%·P0 0건, 40분→28초.
```
