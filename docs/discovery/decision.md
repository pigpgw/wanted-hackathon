# Decision — 최종 선택

## 선정 기준 (2026-09-18 개정)

사용자 명시 기준: **"이미 인터넷에 많이 있는 서비스면 안 됨 — 심사위원·파트너사가 실제로 고민하고 푸는 문제여야 함"**. 따라서 기존 ICE + Judging fit에 **차별성(희소성)** 축을 추가 — 대체재 분석(`docs/discovery/problems.md` P1)으로 실측.

## ICE + Judging Fit + 차별성 점수표

ICE = Impact × Confidence × Ease (각 1~10). 차별성 = "개인이 자연어 서술 → 분해 → 실행"을 제공하는 기존 서비스가 없는가.

## 결론 (한 문장)

**우리는 직장인이 "자기 업무 중 뭘 자동화할지"를 분해·판단할 도구가 없어 AI 활용이 표면에 머무는 문제(P1)를, 업무 서술 → 단계 분해 → 자동화 우선순위 → 샘플 데이터로 실제 1회 실행까지 해주는 "업무→실행 자동화기"(A)로 푼다. 데모 scope는 "업무 서술 입력 → 분해 맵 + 우선순위 → 1개 선택 → 실제 실행 결과물" 핵심 플로우 1개.**

## 근거

1. **심사위원 화두 5/5 정중앙**: 퍼브 김덕중의 직접 화두("자기 업무 해킹" — 업무를 분해해 AI로 전환하는 능력), 원티드(AX 교육→실전 패키지의 빈 구멍), 크래프톤(업무 자동화→창의 업무), 스파크랩(AI 팀원·1인 생산성), 채널코프·라이너(실제 업무에서 일을 끝내는 에이전트). 이들이 회사에서 **돈 주고 푸는 문제의 개인용 버전**.
2. **차별성 실측**: 대체재 분석 결과 "추천·분석·컨설팅"은 존재하나 **"그 자리에서 실행"은 없음** — Panorama(팀 단위·툴 연동 필요·추천까지만), Performi(트래킹·분석만), Zapier Copilot/Make Maia(자기 플랫폼 안 자동화만 제안), QJC(기업 컨설팅). 우리의 "실행" 단계가 빈 구간.
3. **문제 검증 완료**: 한국 근로자 51.8%가 AI를 쓰지만 업무 시간은 3.8%만 감소, 상위 활용이 검색(25%)·요약(15.4%)에 머뭄, 매일 사용자 22% — "쓰긴 쓰는데 업무가 안 바뀐다"가 통계로 확인됨 (T2, `docs/discovery/problems.md` P1).
4. **투표 페르소나 최적**: 투표자 = 원티드 사용자 = 직장인 — "주간 보고서·자료 정리 같은 반복 업무"는 누구나 자기 얘기로 느낌. 예선 20% + 인기상 100% 정렬.
5. **데모 명확성**: "매주 월요일 매출 데이터 정리해서 보고서 쓴다" 입력 → 분해 맵 + 자동화 점수 → 선택 → CSV 올리면 보고서 초안 생성 + "수동 40분 → 30초" 표시. before/after가 한 화면.
6. **AI 활용 적절성**: 비정형 업무 서술의 의미 이해→단계 분해→자동화 적합도 추론→실행 설계는 규칙·템플릿으로 불가 — AI 없이는 아예 안 되는 구조.

## 트레이드오프 인정

- S2a(핏 번역기)는 ICE가 더 높았으나(448), 자소서 AI 계열은 이미 범람 — 사용자 기준("흔한 서비스 제외")에서 탈락. 원티드 도메인 공명은 장점이나 차별성 게이트를 못 넘음.
- A의 리스크: "실행" 단계가 조언으로 끝나면 차별성 소멸 → **실행을 '샘플 데이터 1회 실제 처리'로 스코프 고정**(전체 자동화 파이프라인 구축 아님). 데모에서 실행 결과물이 반드시 화면에 나와야 함 — 이게 성패의 핵심.
- 실행 안전성: 실제 시스템 연동·쓰기 작업은 범위 밖 — 샘플 데이터 입력→결과물 출력(읽기 전용·되돌릴 수 있는 작업)만.

## 데모 scope (핵심 플로우 1개)

1. 사용자가 반복 업무를 자유 서술 (예: "매주 월요일 매출 데이터 정리해서 보고서 써요")
2. 에이전트: 업무를 단계로 분해 → 각 단계에 자동화 적합도 점수(반복성·규칙성·디지털 입출력·소요시간) + 이유 표시
3. 자동화 우선순위 정렬 → 사용자가 1개 선택
4. 샘플 데이터 업로드(CSV/텍스트) → **실제로 1회 실행** (정리·초안·변환 결과물 생성)
5. 결과물 + "수동 예상 시간 → 실행 시간" before/after + 실행 아티팩트(프롬프트팩/SOP) 출력
