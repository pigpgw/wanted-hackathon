# Solutions — 문제별 솔루션 후보

기준: 해커톤 시간(~2일) 내 build cost (S/M/L), 필요 API·데이터 확보 가능성, 리스크, 기존 솔루션 대비 차별점.

## P1 — 자기 업무 해킹

### A. "업무→실행 자동화기" (S1a 강화판) — ✅ 채택
- 접근: 사용자가 반복 업무를 자유 서술 → 에이전트가 업무를 단계로 분해 → 단계별 자동화 적합도 점수(반복성·규칙성·디지털 입출력·소요시간) + 우선순위 → 사용자가 1개 선택 → **샘플 데이터로 실제 1회 실행** → 결과물 + before/after + 실행 아티팩트(프롬프트팩/SOP)
- Build cost: M (웹앱 + LLM + 파일 업로드·실행 1개 플로우)
- 데이터·API: LLM API만으로 가능. 외부 연동 없음 — 실행은 "샘플 데이터 입력→결과물 출력"으로 한정
- 리스크: "실행" 단계가 어드바이스로 끝나면 차별성 없음 — 실행 결과물이 반드시 화면에 나와야 함. 데모 실패 시 조언 서비스로 전락
- 차별점 (대체재 실측, `docs/discovery/problems.md` P1):
  - Panorama — 팀 단위 + 툴 연동 필요 + "추천"까지만
  - Performi — 개인 트래킹·분석만, 실행 없음
  - Zapier Copilot / Make Maia — 자기 플랫폼 안 자동화만 제안 (한국어 미지원)
  - QJC — "무엇부터 AI로 바꿀지" 기업 컨설팅 (개인 도달 안 함)
  - → **개인이 자연어 서술 → 분해 → 우선순위 → 그 자리에서 1회 실행 = 없음.** 추천은 넘치는데 실행이 없음 — 이 갭이 차별점

### S1b. 업무 로그 기반 루틴 분석기
- 접근: 캘린더/업무 기록 붙여넣기 → 루틴 업무 자동 분류 → 자동화 우선순위 리포트
- Build cost: M~L (분석 신뢰도가 핵심이라 프롬프트·평가에 시간)
- 리스크: 출력이 리포트로 끝남 — "작동하는 서비스"의 임팩트가 S1a보다 약함
- 차별점: 진단 특화. 단, 진단 후 실행이 없어 완결성 낮음

## P2 — 공고별 맞춤 지원

### S2a. "핏 번역기" — 공고 요구 ↔ 내 경험 매칭 코치
- 접근: 채용 공고(텍스트/URL) + 내 경험 덤프(자유 서술/이력서) → 요구 역량 추출 → 경험 매핑표(맞음/부분/갭) → 갭을 메우는 맞춤 문단 재작성 + 면접 방어 질문
- Build cost: M (입력 2개 → 3단계 에이전트 파이프라인 → 결과 화면). 2일 충분
- 데이터·API: LLM API + 공고 URL fetch. 실제 원티드 공고로 데모 가능
- 리스크: 매핑 품질이 얕으면 "프롬프트 래퍼"로 보임 → 경험 '조각' 단위 인덱싱과 근거 인용으로 깊이 확보. 주최사 도메인이라 평가가 가장 엄격할 것
- 차별점: 매칭 엔진은 기업용(원티드), 자소서 AI는 단순 생성 — 이건 **구직자 측 번역 엔진**. 공고별 갭 분석+근거 기반 재작성 조합은 없음
- 부가: 투표자(원티드 사용자·구직자)와 정확히 같은 페르소나 — 예선 투표 20%에 최적

### S2b. 지원 트래커 + 공고 분석
- 접근: 공고 모음 관리 + 공고별 요약·일정·요구 역량 자동 정리
- Build cost: M
- 리스크: 트래커는 노션으로도 됨 — AI 필수성 약함 ("왜 AI인가" 기준에 불리)
- 차별점: 약함

## P3 — 1인 사업자 운영

### S3a. "AI 팀원" — 상담·마케팅·운영 3역할 어시스턴트
- 접근: 사업 정보 입력 → 고객 문의 답변 초안 + SNS 콘텐츠 초안 + 주간 운영 리포트
- Build cost: L (3역할을 다 잘 만들 수 없음 — 1개로 좁혀야)
- 리스크: 스코프 초과로 다 얕아짐. 채널톡·마케팅 AI와 정면 비교됨
- 차별점: "담당 역할로서의 AI" 컨셉은 강하나 2일에 실체화 어려움

### S3b. 고객 문의 분류·초안 에이전트
- 접근: 문의 붙여넣기 → 유형 분류 + 답변 초안 + 에스컬레이션 판단
- Build cost: M
- 리스크: 채널톡 ALF가 이미 하는 일 — 파트너사 제품과 겹침
- 차별점: 낮음

## P4 — AI 출력 검증

### S4a. 주장 단위 근거 검증기
- 접근: AI 출력 붙여넣기 → 주장(claim) 추출 → 웹 검색으로 근거 찾아 문장별 표시
- Build cost: L (검색 API + 검증 로직 + 정확도 확보 — 2일 부족)
- 리스크: 검증 자체의 오류. 라이너가 정면으로 하는 일
- 차별점: 후발·약함

## P5 — 교육→실전 단절

### S5a. AX 미션 코치
- 접근: 자기 업무 1개 등록 → 2주 AI 전환 미션 + before/after 리포트
- Build cost: M~L (지속 상태·리마인드 필요 — 2일에 리포트 자동화까지 어려움)
- 리스크: 데모가 "미션 리스트"로 끝날 위험
- 차별점: B2B 컨셉은 원티드 패키지와 보완적이나 검증 불가
