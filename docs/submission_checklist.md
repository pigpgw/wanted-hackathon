## 1. 제출 폼 필수 항목 (모두 채워야 제출됨)

- [ ] **해결하고자 한 문제** — "해결하고자 한 문제를 입력해주세요"
- [ ] **AI 활용 방식 및 결과** — "AI를 주요하게 활용한 부분과, AI를 어떻게 사용했는지 작성" + 결과
- [ ] **사용 AI툴 및 기술 스택** — 1개 이상 선택(태그 형태)
- [ ] **서비스 링크** — 올바른 URL 형식, 심사 기간 접속 필수
- [ ] **서비스 대표 이미지/스크린샷** — 1장 이상, **최대 5장, 16:9 비율**
- [ ] **결과물 게시/홍보 이용 동의** — 체크해야 제출 가능
- [ ] (과제명 등 기본 필드 — 폼 구성에 포함)

## 2. 파일·이미지 규격

- [ ] 10MB 이하
- [ ] PNG / JPG / WEBP만 가능
- [ ] 빈 파일 업로드 불가
- [ ] 이미지 업로드 완료 후에만 저장 가능

## 3. 제출 프로세스 규칙

- [ ] **임시저장은 제출 아님** — 필수 항목 전부 작성 후 제출해야 함. 임시저장만이면 투표·심사 대상 제외
- [ ] 마감 전까지 자유롭게 수정 가능, **마감 후 수정 불가·열람만**
- [ ] **팀장만** 과제 등록·수정 가능 (팀원 계정 불가)
- [ ] 참가 접수 후 과제를 별도 제출해야 참가 완료
- [ ] 허위 기재 시 참가 자격 상실

## 4. 콘텐츠 유의사항

- [ ] 과제에 사용한 **주요 AI 도구의 명칭과 활용 방식 반드시 기재**
- [ ] 배포 툴 자유(Vercel, Railway 등) — **서비스 링크는 심사 기간 동안 접속 가능 상태 유지**, 미접속 시 심사 제외 가능
- [ ] 본인/팀 제작물 — 타인 저작권·상표권·특허권·영업비밀 침해 금지
- [ ] 소속 회사 업무 결과물(직무발명·업무상저작물) 제출 불가
- [ ] 타인 개인정보·소속기관 비밀정보 포함 금지
- [ ] 오픈소스·외부 API·생성형 AI 활용 시 라이선스·이용조건 준수
- [ ] 표절·무단도용 시 참가 자격 제한 또는 수상 취소

## 5. 참가 자격 규칙

- [ ] 개인 또는 최대 5명 팀
- [ ] 만 19세 이상 (참가신청일 기준)
- [ ] 원티드 로그인 필수, 팀원 전원 원티드 회원
- [ ] 1인 1회 — 접수 완료 후 추가 접수 불가
- [ ] 팀장 = 최초 접수자, 팀원 초대링크 1회 발급, 접수 마감 후 사용 불가
- [ ] 소속(학교·회사) 기본 비공개, 선택 공개
- [ ] 제3자 계약·소속기관 규정 위반 참가 불가
- [ ] 주최사·계열사 임직원 참가 가능하나 수상 제외
- [ ] 약관·개인정보 수집 이용 동의 필수

## 6. 본선·수상 규칙

- [ ] **상위 진출자는 오프라인 본선 참석·과제 발표 필수 — 불참 시 심사·수상 제외**
- [ ] 본선 촬영물은 홍보자료·보도자료로 활용될 수 있음
- [ ] 상금은 제세공과금 원천징수 후 지급
- [ ] IP는 참가자 귀속, 주최사는 운영·심사·홍보 목적으로 무상 이용 가능 + **대회 종료 후에도 사이트 게재 가능**

- [ ] 예선 투표 (9/21~10/5): "내 투표가 TOP 20 선정에 반영됩니다. **과제당 1회 투표**"
- [ ] 인기상 투표 (10/7~10/15): "TOP 20 중 인기상 수상작을 뽑아주세요. **예선 투표 결과는 그대로 반영**되며, 과제당 1회 투표"
